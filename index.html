❮ The Club ❯

Kellett Kodes is a student-led after-school ECA open and accessible to anyone from Y7-Y13. This term the focus is game development, with sessions on Ren’Py for beginners and Godot for more advanced coders, two amazing game engines. You’ll create your own games, by yourself or in groups (get your friends to join!), gaining first hand experience with game dev. Your work will culminate in a student showcase near the end of each term! The best projects will win prizes such as games, desktop gear, and grants for the game to be uploaded to steam. There may be free food!
For new coders, we offer lunchtime programming sessions on the side, so don’t worry if you can’t code yet! The skills these mini lessons teach are completely transferrable to the after-school game development sessions, so everyone will gain something from this program. Moreover, we’ll provide an overwhelming amount of resources for you to learn programming in your free time.
